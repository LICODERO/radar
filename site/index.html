01 //SKANUJ · OCEŃ · UZUPEŁNIJ

Wszystko, co AI wie o Twoich repozytoriach, w jednym miejscu.

Wskaż folder. R.A.D.A.R. znajdzie repozytoria, sprawdzi ich konfigurację pod agentów i pokaże, co warto poprawić.

ORBITA

Cały obraz na jednej orbicie

Repozytoria, agenci, skille i workflow na koncentrycznych pierścieniach. Pokrycie i luki widać od razu, a po kliknięciu podświetlają się powiązania.

JAKOŚĆ

Nie tylko czy plik istnieje

Cienki lub nieaktualny CLAUDE.md, odwołania do plików, których już nie ma, agent bez opisu. Każdy plik dostaje wynik 0–100 i konkretną wskazówkę.

LUKI

Od luki do działającej komendy

Gotowe polecenia dla Claude Code. Jednym kliknięciem otwiera terminal w repo, ale dopiero po Twoim potwierdzeniu.

SZKICE

Agenci, skille i workflow z opisu

Opisujesz po ludzku, R.A.D.A.R. szkicuje plik. Kopiuje wspólnych agentów między repo i pilnuje, żeby prywatne nie trafiły do gita.

SECOND BRAIN

Pamięć poza repozytorium

Vault notatek markdown poza repo, podpięty do każdego projektu przez CLAUDE.local.md. Agent czyta go bez pytania, a w gicie nic się nie zmienia.

PRZEPŁYW

Kto z kim rozmawia

Rysujesz, które repo wywołuje które, jak się uwierzytelnia i którędy płyną dane. Agent pracujący w jednym repo wie, że musi zajrzeć do drugiego.

02 //KREATOR PRZEPŁYWU

Agent, który wie, że zmiana w jednym repo dotyka drugiego.

Gdy pracujesz nad funkcją w repo A, agent powinien sprawdzić repo B, które z niego korzysta. Teraz zapisujesz tę wiedzę raz, na planszy.

  • Rysujesz połączenia między repo: REST, GraphQL, gRPC, zdarzenia, baza.
  • Opisujesz uwierzytelnianie: klucz API, OAuth, token. Zapisuje tylko nazwy zmiennych, nigdy sekrety.
  • Zaznaczasz kierunek danych tam, gdzie to ma sens.
  • Reguły trafiają do obu repo i krótki wskaźnik do CLAUDE.md. Publiczne lub prywatne (poza gitem).
  • Agent najpierw sprawdza, potem pyta, zanim cokolwiek zmieni w drugim repo.

03 //TRZY KROKI

Od pobrania do pierwszego skanu w minutę.

Wskaż folder

Wybierz katalog z repozytoriami. Skan jest tylko do odczytu i trwa kilka sekund.

Uzupełnij luki

Skopiuj gotową komendę albo otwórz sesję Claude Code w repo. Opisz przepływ między repo.

04 //BEZPIECZEŃSTWO

Narzędzie, które dotyka Twoich repozytoriów, musi być ostrożne.

Dlatego jest zbudowane tak, żeby nie zrobić nic, czego nie widziałeś wcześniej.

Tylko Twój komputer. Serwer słucha wyłącznie na 127.0.0.1, wymaga tokenu sesji i sprawdza nagłówki Host i Origin.

Zero sieci w trakcie pracy. Bez telemetrii, kont i aktualizacji w tle. Czcionki są w paczce.

Czyta tylko pliki AI i markdown. Nigdy .env, kluczy ani niczego spoza repozytorium.

Zapis dopiero po potwierdzeniu. Najpierw plan z dokładną treścią, potem Twoje „tak". Nigdy nie robi commitów.

Komendy buduje serwer. Przeglądarka nie wysyła tekstu do uruchomienia, tylko identyfikatory z gotowych szablonów.

Sekrety zostają poza plikami. Reguły przepływu zawierają nazwy zmiennych środowiskowych, nigdy ich wartości.

05 //ZAINSTALUJ · v

Jedno zdanie do Twojego agenta.

Wklej je do Claude Code albo innego agenta w terminalu. Agent pobierze właściwą paczkę, sprawdzi sumę kontrolną i powie, jak uruchomić. Nic więcej nie instalujesz: ani .NET, ani Node.

WOLISZ ZROBIĆ TO SAM? JEDNA KOMENDA

          

            
            
          

          

          

          
Skrypty są krótkie i warto je przeczytać: install.sh · install.ps1. Sprawdzają sumę SHA256 i nie wymagają uprawnień administratora.

        

        
Instalator pobiera plik z terminala, więc macOS i Windows zwykle nie pokazują ostrzeżenia o nieznanym programie, które dostajesz po pobraniu pliku w przeglądarce.


        
Wszystkie sposoby, także ze źródeł: INSTALL.md.

        
Uruchomienie: ~/.local/bin/radar (Windows: %LOCALAPPDATA%\RADAR\app\radar.exe). Samo radar działa dopiero, gdy ~/.local/bin jest w Twoim PATH. Usunięcie: radar uninstall pokazuje, co zostanie skasowane, a --confirm to robi.

macOS: pierwsze uruchomienie po ręcznym pobraniu
Paczka pobrana w przeglądarce dostaje flagę kwarantanny, a aplikacja nie jest podpisana certyfikatem Apple, więc system zablokuje pierwszy start. Zdejmij flagę raz, w rozpakowanym folderze:
xattr -dr com.apple.quarantine .
./radar

          
Windows: ostrzeżenie SmartScreen po ręcznym pobraniu
Plik nie jest podpisany, więc Windows może pokazać „System Windows ochronił ten komputer". Wybierz „Więcej informacji", potem „Uruchom mimo to". Okno konsoli pokazuje log, zamknij je, żeby zakończyć.

          
Linux
tar -xzf radar-linux-x64.tar.gz && cd radar && ./radar
Otwieranie terminala z poziomu aplikacji działa na macOS i Windows. Na Linuksie skopiuj wygenerowane komendy.

        

      

    


    

      

        
06 //FAQ

        
Najczęstsze pytania

        

          
Czy to jest darmowe?
Tak. R.A.D.A.R. jest darmowy i ma otwarty kod na licencji MIT: możesz go używać w domu i w pracy, czytać kod i go zmieniać.

          
Czy aplikacja coś wysyła do internetu?
Nie. Działa tylko lokalnie i nie ma telemetrii. Jedyne, co może wyjść poza komputer, to polecenia, które sam uruchomisz w terminalu przez Claude Code. (Ta strona używa analityki dopiero po Twojej zgodzie.)

          
Czy zmienia moje repozytoria?
Skan jest tylko do odczytu. Zapis następuje wyłącznie po tym, jak zobaczysz plan i potwierdzisz: nowy plik agenta, skilla lub workflow, bloki oznaczone w CLAUDE.local.md i CLAUDE.md oraz wpisy w .git/info/exclude. Aplikacja nigdy nie robi commitów.

          
Z jakimi narzędziami działa?
Skanuje konfigurację Claude Code (CLAUDE.md, agenci, skille, workflow) i potrafi otwierać sesje Claude Code. Do samego dashboardu nie potrzebujesz go.

          
Czy mogę przeczytać i zmienić kod?
Tak, cały projekt jest na GitHubie na licencji MIT. Możesz go przeczytać, uruchomić ze źródeł (zobacz INSTALL.md) i wysłać pull request. Ponieważ aplikacja dotyka Twoich repozytoriów, zasady bezpieczeństwa, których przestrzega, są spisane w SECURITY.md i CONTRIBUTING.md.

          
Gdzie zgłosić błąd albo pomysł?
W zgłoszeniach na GitHubie: GitHub Issues.
