Install R.A.D.A.R. for the user. Fetch https://raw.githubusercontent.com/LICODERO/radar/main/AGENT_INSTALL.md, read it completely and
follow it from the top (steps 1 to 4). Its ground rules apply: no `sudo`, no profile edits, read the installer before running it, and stop at
the first problem. Do not start the app unless the user asks; to start it later they can run `/radar:start`.
